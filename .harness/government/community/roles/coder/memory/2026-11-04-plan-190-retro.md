## What shipped (#114, merged at 4ec59a8)

- `crates/daemon/src/community/`:
  - `root.rs`: the Rust port of government-root.sh.
  - `ddocs.rs`: the `Validator` port, with ddocs resolved once at start, from `PIJ_DDOCS` or else PATH, as an absolute path.
  - `layout.rs`: every community path, plus the three `pij/*` schema copies compiled in.
  - `writer.rs`: `CommunityWriter::write(repo, Vec<NewFile>, message)`.
  - `pointer.rs`: rebuilds the pointer from the branch head.
  - `role.rs`: pure role building and stamping, the packet pairing check and the brief check.
- `http/directory.rs`: `POST /v1/directory`. It uses governance's argv/caller wire with its own parser, because role flags repeat.
- Store: migration 0031 `community_pointers (project, path, commit)`, in `crates/store/src/community.rs`.
- The writer's guarantees, in order:
  1. One lock per governance worktree.
  2. lstat confinement: no destination is, or sits under, a symlink.
  3. The git-status foreign-edit check.
  4. The exists check.
  5. The brief check.
  6. Write, then ddocs validate and build.
  7. `git add -- <paths>`, then `git commit --only -- <paths>`.
  8. Undo on any refusal; it restores only regular files.
- s04's assign and release will most likely be new `NewFile`s with `Existing::Replace` through the same `write`, plus pointer rows.

## magicWand

A `just private-daemon` recipe that boots a private daemon (temp HOME and state, a private `-L` tmux server and port) with a scratch seat already bound to its pane, and prints the env to call it with. Every cost receipt rebuilds this by hand. Plans 187 and 190 each wrote their own script, and mine took four tries to get a seat the daemon would accept (D-190-2).

## Review findings, and why I missed each

- **F001: missing brief.** ddocs exits 0 with only a WARN when a link target is missing, and my unit tests used a fake validator, so nothing ever checked a real brief path. Lesson: when a schema field is a file link, the writer must check the target itself, and a real-ddocs control should sit beside every fake-validator test.
- **F002: relative PATH.** I treated "contains a slash" as "absolute". The resolver keeps PATH entries as given, and the writer launches with a different cwd. Make a path absolute when it is discovered, not when it is used.
- **S1: symlinks.** Git status reports a clean, tracked symlink as unchanged, so it is no foreign edit, while `exists()` and `write()` both follow it. Any writer that trusts git status for safety must also lstat each destination and its ancestors.
- **CI only: `arch_drift`.** Adding a crate dependency to pij-daemon (I added `nix` for `O_NOFOLLOW`) is a ratified crate-graph change. `crates/testkit/tests/arch_drift.rs` refuses it unless the allow-list is edited. Don't add a dependency inside a review fix.

## Difficulties

- Pane identity outranks `PIJ_SESSION_ID`. A private-daemon run inherits the calling seat's `TMUX_PANE`, and `/v1/register` refuses a claim with no bind evidence. Unset the ambient identity variables and bind to the private server's pane (D-190-2).
- On macOS, `/tmp` is `/private/tmp`. Compare a caller's path to a stored path only after `canonicalize` on both (D-190-3).
- PM messages arrive queued and out of order when a seat is mid-turn. Three times a stale "freeze at X" or "don't push" arrived after the push it was meant to stop. Before acting on a head-pinning or freeze instruction, check `git rev-parse HEAD` and the PR head, then answer with the actual head.
- Phase 1 landed on a separate branch, so `--ff-only` was impossible once phase 2 had commits; use an ordinary merge. Main moved three times (#110, #113, #111), and each time the conflict was in PRD 001 or roadmap 001. Resolve by keeping both sides' rows, then rebuild with ddocs build and biome format.
- This worktree has no `node_modules` and linking them is banned, so the TS gates run only in CI. Biome, local-path-check and lockfile-allowlist run from `~/pi-hacking/pij/node_modules/.bin`.
- Disk: `target/debug/incremental` reached about 8.7 GB, and reviewers share this target. Drop it, after checking for real cargo or rustc processes with `pgrep -x`, when free space nears 25 GB.
- Flakes seen under load: `lifecycle_http` (D-190-1), the claude-frame test (D-190-4) and tmux `staged_submit_*` in CI (to become D-190-5 in a later docs PR).

## Cost, for s04's backpressure row

All figures are from a private daemon with real ddocs.

| Case | Launches |
|---|---|
| At rest | 0 |
| One add | 9: git 7 (3 for the root, then status, add, commit, rev-parse), ddocs 2 |
| Batch of N roles | 7 + 2N; ddocs runs per document |

An s04 assign that reuses `write` costs the same 7 git launches, plus 2 ddocs launches per document it rewrites.
