## CPU-unit control and AFTER recipe

Do not treat the raw macOS resource CPU fields as nanoseconds. On this host they are Mach ticks. `mach_timebase_info` returned numerator **125**, denominator **3**. The converted control was 344.676674708 seconds, independently matching `/bin/ps` `5:44.68`. A preliminary unconverted control disagreed with ps and was rejected before either API probe.
