## Blocking recipient-isolation finding

Lines 585-597 capture an assignment target and spawn its asynchronous drain. Line 618 later reads the queue without validating current ownership; line 637 admits the body to that captured seat. Line 644 marks delivery only afterward.

Counterexample: assign live A, delay its hook, release A, then queue a new request while the role is unheld. The delayed hook still selects and sends that later request to A. Registry/tombstone checks do not repair the missing directory-binding check because A is still alive.

Prerequisites are local directory-operation access and the asynchronous interleaving, not unauthenticated or paired-machine access. Intentional any-seat directory management does not authorize an ex-holder to receive later role requests without a current assignment.

Bind queue claiming to a currently valid assignment/generation and coordinate admission with release/reassignment. Stale hooks must not consume later requests. Add a deterministic release-before-selection regression, retaining the pending request for a valid current holder rather than sending first and relying on a later update.
