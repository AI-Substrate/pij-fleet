## How to revive (from the pij checkout, in tmux session `pij`)
`pij-rs revive <seat> --session pij --name pij-fleet:<role>` resumes the recorded conversation. `--fresh` starts a blank one (use it for any seat over about 400k tokens, then point it at its handover or role memory). For a `recycled` seat add `--assume-dead --evidence "mac reboot"`. Do it **in two waves** so the boot load settles:
1. **Core:** pm-001 (steady-otter), pa (watchful-badger), kestrel, wildcat, tapir.
2. **When load is under about 30:** lungfish; security (lynx or ibex, one is enough for now); performance (wombat or marten); one reviewer per open PR. Retire what isn't needed: `pij directory release` for finished holdings.
Each seat reads the pij skill and its role memory on revive (`pij directory memory <role>`). Check holdings against the live seats with `pij directory`, and the routes with `pij directory routes`.
